About ZAP Automation Plans

ZAP Automation Framework plans define the scanning workflow using YAML configuration. Plans can include:

  • Spider: Crawl the target to discover URLs
  • Ajax Spider: Use a headless browser for JavaScript-heavy applications
  • Active Scan: Perform security vulnerability scanning
  • Passive Scan: Analyze traffic without active attacks

Learn more in the ZAP Automation Framework documentation.
