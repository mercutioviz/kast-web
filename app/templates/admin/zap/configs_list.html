About ZAP Configurations

ZAP configurations define how and where ZAP scans are executed:

  • Local (Docker): Run ZAP in a Docker container on the same machine
  • Remote: Connect to an existing remote ZAP instance
  • Cloud: Launch ZAP instances in cloud environments (AWS, GCP, Azure)
  • Auto: Automatically select the best available method

Test configurations before use to ensure connectivity and proper setup.
