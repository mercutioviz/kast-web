About ZAP Configurations

ZAP configurations define how and where ZAP scans are executed:

  • Ephemeral Docker: kast launches a fresh ZAP container per scan and tears it down on completion
  • Server ZAP: kast-web manages a persistent ZAP Docker container on this host; use Start/Stop/Status to control it
  • External ZAP: Connect to a pre-running ZAP API server at an external host
  • Cloud: Launch ZAP instances in cloud environments (AWS, GCP, Azure)
  • Auto: Automatically select the best available method

Test configurations before use to ensure connectivity and proper setup.
