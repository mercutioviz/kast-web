Execution Modes
Local (Docker)

Runs ZAP in a Docker container on the same machine. Requires Docker to be installed and running.

Remote

Connects to an existing ZAP instance running elsewhere. Useful for dedicated ZAP servers.

Cloud

Launches temporary ZAP instances in cloud providers (AWS, GCP, Azure). Requires cloud credentials and Terraform.

Auto

Automatically selects the best available method based on environment.

CIDR Blocks

CIDR blocks define which IP addresses can access your cloud ZAP instance.

  • Single IP: 203.0.113.50 (auto-adds /32)
  • Subnet: 192.168.1.0/24 (256 IPs)
  • Range: 10.0.0.0/16 (65,536 IPs)
  • Any IP: 0.0.0.0/0 (⚠️ Not recommended)
Security Notes
  • API keys and credentials are encrypted at rest
  • Sensitive data is never shown in logs
  • Use strong, unique API keys
  • Restrict CIDR blocks to known IPs only
  • Test configurations before production use
  • Cloud resources auto-terminate after scans
