Execution Modes
Local (Docker)

Runs ZAP in a Docker container on the same machine. Requires Docker to be installed and running.

Remote

Connects to an existing ZAP instance running elsewhere. Useful for dedicated ZAP servers.

Cloud

Launches temporary ZAP instances in cloud providers (AWS, GCP, Azure). Requires cloud credentials.

Auto

Automatically selects the best available method based on environment.

Security Notes
  • API keys and credentials are encrypted at rest
  • Sensitive data is never shown in logs
  • Use strong, unique API keys
  • Restrict network access to ZAP instances
  • Test configurations before production use
